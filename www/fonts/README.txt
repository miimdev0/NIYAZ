  Doran.woff2   یا   Doran.woff   یا   Doran.ttf   یا   Doran.otf        ← وزن معمولی
  Doran-Bold.woff2 یا Doran-Bold.woff یا Doran-Bold.ttf یا Doran-Bold.otf  ← وزن ضخیم (اختیاری)

اگر فقط یک فایل داری، همان را با نام Doran.ttf (یا woff2) ذخیره کن؛ برای تیترها هم از همان استفاده می‌شود.
